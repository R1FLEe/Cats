NETFIX - набор для починки кабельного интернета на Windows с помощью opencode
===========================================================================

ЧТО ВНУТРИ
  AGENTS.md     - главный промт (правила + методика). opencode сам подхватывает его из папки, где запущен.
  diag.ps1      - скрипт диагностики. НИЧЕГО не меняет в системе, только пишет отчёты в C:\netfix\out\
  START.txt     - стартовое сообщение для агента (заполнить и вставить) + запасной короткий промт.
  opencode.json - opencode будет спрашивать разрешение на каждую команду и правку файла.
  README.txt    - этот файл.

КАКУЮ МОДЕЛЬ ВЫБРАТЬ
  Qwen 27B - основная. Плотная (dense) модель: лучше держит длинную диагностику и реже выдумывает команды.
  gpt-oss-20b - запасная: если Qwen работает медленнее ~5 токенов/с или зацикливается. Ставь reasoning effort = high.
  Если хватает видеопамяти - подними контекст Qwen до 48-64k (помогает KV-cache q8_0).


0. СНАЧАЛА 2 МИНУТЫ РУКАМИ (может решить сразу)
  - Параметры -> Сеть и Интернет -> Прокси-сервер -> выключи "Использовать прокси-сервер"
    и "Использовать сценарий настройки". Особенно если браузер пишет
    "Прокси-сервер отказывается принимать соединения" / ERR_PROXY_CONNECTION_FAILED.
  - В трее или в диспетчере задач есть Hiddify, v2rayN, NekoBox/Throne, Clash, WARP, Amnezia,
    winws/zapret, GoodbyeDPI? Полностью закрой и проверь интернет.
  - Красный крестик "Сетевой кабель не подключен": Shift + "Завершение работы",
    выдерни ПК из розетки на 1 минуту, включи.
  - USB-модем с Android-телефона: если через него интернет ЕСТЬ - сломан именно Ethernet
    (драйвер или настройки адаптера); если НЕТ - общая настройка (прокси, VPN, файрвол, DNS, Winsock).
    Запомни результат и потом ОТКЛЮЧИ модем.


1. КАК ПЕРЕНЕСТИ ФАЙЛЫ НА ПК БЕЗ ИНТЕРНЕТА
  - Android + USB-кабель: в шторке уведомлений телефона "USB: зарядка" -> "Передача файлов".
    На ПК в Проводнике появится телефон -> папка Download -> скопируй netfix.zip на ПК.
  - USB-модем (Android): Настройки -> Точка доступа и модем -> USB-модем. Если на ПК появился
    интернет - открой чат с Claude на ПК и скачай файлы оттуда.
  - Флешка: через другой компьютер или телефон с OTG-переходником
    (iPhone 15 и новее с USB-C - через приложение "Файлы").
  - Bluetooth: на ПК Параметры -> Bluetooth -> "Отправка и получение файлов" -> "Принимать файлы",
    на телефоне "Поделиться" -> Bluetooth.
  - iPhone по кабелю Windows видит только как фотоаппарат - файлы так не перекинуть.
  - Ничего не вышло - набери руками короткий промт из START.txt (часть 2).

  Распаковка: правой кнопкой по netfix.zip -> "Извлечь всё" -> в поле пути напиши C:\
  Должно получиться C:\netfix\AGENTS.md, C:\netfix\diag.ps1 и т.д.


2. ДИАГНОСТИКА (1-3 минуты)
  Пуск -> набери PowerShell -> правой кнопкой -> "Запуск от имени администратора". Выполни:

    powershell -NoProfile -ExecutionPolicy Bypass -File C:\netfix\diag.ps1 -Since ГГГГ-ММ-ДД

  где дата - день ПЕРЕД сессией с агентом (например, сессия была 22.11 -> -Since 2026-11-21).
  Не помнишь дату - запусти без -Since (возьмёт последние 5 дней).
  Результат: C:\netfix\out\report.txt (главное) и C:\netfix\out\changes.txt (что менялось).
  Уже на экране будут RED FLAGS и строка BREAKS AT - часто причина видна сразу.


3. ЗАПУСК АГЕНТА
  В том же окне администратора:
    cd C:\netfix
    opencode
  В opencode: /models -> выбери Qwen 27B.
  Полезно: /sessions -> открой вчерашнюю сессию и пролистай, какие команды запускал агент
  (winget, pip, reg, netsh, zapret, v2ray, proxy...). Выпиши главное. Потом /new - новая чистая сессия.
  Открой START.txt, заполни места с ____ и вставь часть 1 в opencode.


4. ВО ВРЕМЯ РАБОТЫ
  - opencode будет спрашивать разрешение на каждую команду. Читай, что агент собирается сделать.
    Диагностику (Get-..., ping, Resolve-DnsName, чтение файлов) смело разрешай.
    Изменения - только после того, как агент показал "Причина / Доказательства / План / Откат"
    и ты ответил "ОК".
  - Агент начал тупить, повторяться или кончился контекст: /compact, либо /new и напиши:
    "Прочитай C:\netfix\NOTES.md и C:\netfix\AGENTS.md и продолжай с того места".
  - opencode не может достучаться до модели (LM Studio / Ollama)? Скорее всего, в системе прописаны
    переменные HTTP_PROXY/HTTPS_PROXY - это тоже улика. Временно в PowerShell:
      $env:NO_PROXY = 'localhost,127.0.0.1'
    и запусти opencode заново.
  - opencode ругается на opencode.json - удали этот файл, правила безопасности всё равно есть в AGENTS.md.
  - Если подключён USB-модем, проверки пойдут через телефон. Для проверки кабеля модем надо отключить.


5. ЕСЛИ НЕ ПОЛУЧИЛОСЬ
  Перекинь на телефон C:\netfix\out\report.txt, C:\netfix\out\changes.txt и C:\netfix\NOTES.md
  и пришли их в чат Claude - разберу и дам точные команды.
  Паролей в отчётах нет, но там может быть имя пользователя Windows в путях
  и куски вчерашних команд агента - глянь, если это важно.
